# Anup Yadav — Portfolio

A responsive, reference-inspired personal portfolio built with HTML, CSS and JavaScript.

## Preview locally
Open `index.html` in a browser.

## Deploy on Vercel
1. Upload the files in this folder to a GitHub repository.
2. Sign in at https://vercel.com and choose Add New → Project.
3. Import the GitHub repository.
4. Select **Other** as the framework preset (static HTML), then deploy.
5. Vercel will provide a `*.vercel.app` URL.
